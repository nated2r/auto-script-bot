# 自動產稿機器人｜產品簡報

風格參考你 ChatGPT「記住簡報風格」對話：16:9 資訊圖卡、LINE 綠＋深藍、大標題、圓角卡片、底部 slogan。

## 建議看這個（新｜圖卡版）

| 檔案 | 說明 |
|------|------|
| `自動產稿機器人_產品簡報_圖卡版.pptx` | **整頁圖卡**嵌入 PPT，最接近參考風格 |
| `自動產稿機器人_產品簡報_圖卡版.html` | 瀏覽器翻頁預覽（方向鍵） |
| `ppt-slides/*.png` | 單頁 PNG（可丟 Canva／再修圖） |
