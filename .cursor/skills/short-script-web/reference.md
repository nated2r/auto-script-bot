# 產稿網頁｜補充參考

Agent 實作細節需要時再讀本檔；日常以 SKILL.md 為主。

## 與 Claude Project 用法的對應

原交付包設計給 Claude Project Instructions + Knowledge。網頁版對應：

| 原用法 | 網頁 |
|--------|------|
| Project Instructions = 系統層指令 | 伺服端 system／developer 訊息（讀 txt） |
| Knowledge 模組 | 依路由按需讀 md；MVP 可只讀系統層＋禁止題材 |
| 首次對話帳號變數 | 自定義規則持久化（localStorage 或後端 user settings）；空白欄不覆寫 |
| 方式 A「展開題材」 | 題材輸入 → ANGLE 角度 1…7（可一次一角） |
| 方式 B「貼稿改爆款」 | 主輸入框貼稿 → ANGLE_MATRIX 重寫 |

## 禁止使用的題材（原稀釋清單）

- 檔案仍名為 `稀釋題材預警清單_通用版.md`，UI／設定稱「禁止使用的題材」  
- 通用版多為空模板；使用者在教育區自填的禁題應合併進每次檢查  
- 有明確鉤子（測驗／反直覺／場景代入）可放行的邏輯見該 md  

## 六欄輸出（貼 Sheet）

欄序固定、欄間勿空行：

1. 封面文案  
2. 影片標題  
3. 口播稿  
4. 內文  
5. hashtag  
6. 懶人包整理  

封面／內文／懶人包若有換行，內容用 ASCII `"` 包住。

## DeepSeek 建議加掛的短約束（示意）

在帳號設定之後追加一段固定文字即可，例如：

- 一律台灣繁體中文，禁止簡體字  
- 禁用陸網用語（如：視頻、點讚、搞錢、挺好的）  
- 語感對齊使用者提供的「口播文案參考區」範本  
- 與系統硬規則衝突時以硬規則為準
