# 短影音自動產稿｜網頁 Skill

## 何時使用

- 在本 repo 建立／修改產稿網頁範本
- 串接 LLM（預設 DeepSeek）與知識檔產稿
- 實作自定義規則、要／不要、自訂指令

## 開工前必讀

1. @00_使用說明_先讀我.md  
2. 產稿邏輯：@系統層指令_通用版.txt（重點：ANGLE_MATRIX、口播稿製作規範）  
3. 題材閘門：@稀釋題材預警清單_通用版.md（UI 名稱＝「禁止使用的題材」）  
4. 細節與 MVP 邊界：[reference.md](reference.md)

## MVP 範圍（先做這些）

1. 輸入：貼新聞稿 **或** 參考口播 +「改成爆款／30 秒口播」  
2. 設定：自定義規則（見下）  
3. 後端／API：組 prompt → 呼叫模型 → 回傳六欄稿  
4. 路由：貼參考稿改寫 → ANGLE_MATRIX；給題材可先只出角度 1（反直覺）  
5. 暫不做：11 模組完整帳號經營後台（需要再掛）

## 自定義規則欄位（區塊名稱固定）

- 身份  
- 語氣  
- **必要有的 hashtag 跟 CTA**  
- 要／不要  
- **口播文案參考區**  
- **禁止使用的題材**  
- （進階）自訂指令  

**增量覆寫**：空白＝系統原始設定；有填才覆寫該欄（勿對空欄送「未填」）。

## Prompt 組裝

順序：系統硬規則 → 自定義規則（僅非空欄位）→ 本次輸入。  

實作要點：

- 伺服端讀知識檔，勿把完整系統指令暴露在前端 bundle  
- DeepSeek：強制繁中（台灣）、禁用陸用語；務必帶「口播文案參考區」範本（有填時）  
- API Key 僅環境變數  
- 產稿前套用「禁止使用的題材」；命中無鉤子則先預警  

## 建網頁範本時

- 繁中 UI；設定頁 label 與上表一致  
- 產出區方便複製六欄（對 Google Sheet）  
- 技術棧未指定時：選簡單可部署方案（例如 Vite + 一個 API route／serverless），先問再鎖  

## 不要做

- 不要在未確認下刪除或大幅重寫 `系統層指令_通用版.txt`  
- 不要讓自訂指令覆寫六欄格式／字數／一次一角度  
- 不要把密鑰寫進 repo
